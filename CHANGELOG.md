# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантические](https://semver.org/lang/ru/).

## [0.1.0] — первая публичная версия

### Возможности
- Сканирование архива VK по вкладкам «Сообщения», «Стена», «Профиль», «Лайки и
  закладки» со статистикой по видам файлов (фото, голосовые, документы, видео).
- Загрузка по прямым ссылкам и встраивание файлов в HTML: картинки, аудио- и
  видеоплееры, ссылки на документы. Резервные копии исходных страниц в `_backup_html/`.
- Вход по cookie браузера (JSON Cookie-Editor, `cookies.txt`, строка заголовка).
  Вложения из переписок и со стены получаются через API веб-версии VK с ключами
  доступа (`messages.getById`, `wall.getById`, `wall.getComment`), фото и видео — через
  `photos.getById`/`video.get`, документы — со страниц документов.
- Отдельный выбор видов файлов для личных переписок, бесед и сообществ;
  ограничение качества видео.
- Временные и окончательные ошибки, повтор недоступных ссылок, автоматическая остановка
  при странице входа или капче, предохранитель при недоступном API.
- «Тест на примерах» для проверки на настоящем VK без изменения архива.
- «Обновить страницы»: пересборка HTML раздела из резервных копий.
- GUI на tkinter и командная строка; Windows, Linux, macOS; только стандартная
  библиотека Python 3.8+.
- Тесты на имитации VK (`tests/`).
